## ⚡ Core Architecture & Highlights

* **🤖 3D Cybernetic Avatar Core (WebGL / Three.js)**:
  * Procedurally built cybernetic android avatar with real-time cursor head tracking and breathing kinematics.
  * Interactive HUD controls: **X-Ray Core Wireframe**, **Hologram Glitch Mode**, **Kinematics Scan Line**, **Color Theme Cycling**, and **360° Auto-Orbit**.
* **🧠 Dedicated 3D Mini-Scenes for Engineering Case Studies**:
  * **AI Study Assistant**: 3D interactive neural vector embedding graph.
  * **Urban Traffic Digital Twin**: Real-time LiDAR point cloud simulation.
  * **Earth Observation & NDVI Satellite**: Orbital satellite tracking globe.
  * **Retail Sales Predictive Forecaster**: 3D time series demand ribbons.
  * **Automated Startup Valuation Engine**: Multi-dimensional valuation plane.
* **🔊 Audio Engine & Web Speech Voice Greeting**:
  * Auto-welcome introductory sequence synthesized via Web Speech API upon visitor arrival.
  * Web Audio API synthesized frequency clicks and audio feedback.
  * Global persistent ON/OFF audio toggle with state memory.
* **🎨 Obsidian-Slate Enterprise Visual Theme**:
  * Deep obsidian void (`#080B11`) with subtle studio spotlights and cyan/emerald status accents.
  * Tailored for tech recruiters, engineering managers, and technical leaders.
* **📬 Recruiter Mission Control & Direct Email Dispatch**:
  * Direct email routing to **`niladri6202@gmail.com`**.
  * 1-Click **Open in Gmail** and **Open in Outlook** webmail launchers with full dossier pre-populated.
  * Native mail client (`mailto:`) invocation and automated clipboard safety backup.
* **📄 Interactive PDF CV Viewer**:
  * Dual-mode view toggle (Live interactive web layout vs. Full-page embedded PDF viewer) with direct download capabilities.

## 🚀 Running Locally

This project requires no build tools or package managers. Any static HTTP server can serve it directly:

### Option 1: Python
```bash
python -m http.server 8000
```
Open [http://localhost:8000](http://localhost:8000) in your web browser.

### Option 2: Node.js (npx)
```bash
npx serve .
```
